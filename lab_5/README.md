# Лабораторна робота №5 — Наука про дані: обмін результатами та початковий аналіз

## Опис
Веб-додаток для аналізу VHI даних по областях України.
Дані завантажуються автоматично з NOAA при першому запуску.

## Запуск
```bash
pip install -r requirements.txt
py -m streamlit run lab_5.py
```

## Функціонал
- Вибір часового ряду (VHI/VCI/TCI)
- Вибір області
- Фільтрація по тижнях та роках
- Сортування даних
- 3 вкладки: таблиця, графік, порівняння областей

## Вимоги
- Python 3.8+
