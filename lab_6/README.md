# Лабораторна робота №6 — C++ OpenCV

## Опис
Програма читає відео з камери та дозволяє застосовувати різні фільтри обробки зображень в реальному часі.

## Вимоги
- Ubuntu 20.04+
- GCC 11+
- CMake 3.10+
- OpenCV 4.x
- Вебкамера

## Встановлення залежностей
```bash
bash preinstall.sh
```

## Збірка
```bash
bash build.sh
```

## Запуск
```bash
bash run.sh
```

## Керування
| Клавіша | Дія |
|---------|-----|
| N | Нормальний режим |
| I | Інверсія кольорів |
| B | Gaussian blur |
| C | Canny фільтр |
| S | Фільтр Собеля |
| G | Відтінки сірого |
| ЛКМ | Намалювати кружок |
| ПКМ | Прибрати кружок |
| ESC | Вихід |

## Архітектура
- `CameraProvider` — захоплення відео з камери
- `KeyProcessor` — обробка клавіатури та режимів
- `FrameProcessor` — обробка зображень
- `Display` — відображення результату та обробка миші
