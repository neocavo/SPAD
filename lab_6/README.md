# Лабораторна робота №6 — C++ OpenCV

## Опис
Програма читає відео з камери та дозволяє застосовувати різні фільтри обробки зображень в реальному часі за допомогою OpenCV.

## Вимоги до ОС та заліза
- **ОС:** Ubuntu 20.04+
- **Компілятор:** GCC 11+ або Clang 12+
- **CMake:** 3.10+
- **OpenCV:** 4.x
- **Камера:** вбудована або USB вебкамера
- **RAM:** мінімум 2 ГБ

## Клонування репозиторію
```bash
git clone https://github.com/neocavo/SPAD.git
cd SPAD/lab_6
```

## Встановлення залежностей
```bash
./preinstall.sh
```

## Збірка
```bash
./build.sh
```

## Запуск
```bash
./run.sh
```

## Або одною командою
```bash
./preinstall.sh && ./build.sh && ./run.sh
```

## Керування
| Клавіша | Дія |
|---------|-----|
| N | Нормальний режим |
| I | Інверсія кольорів |
| B | Gaussian blur |
| C | Canny фільтр |
| S | Фільтр Собеля |
| G | Відтінки сірого |
| ЛКМ | Намалювати кружок на кадрі |
| ПКМ | Прибрати кружок |
| ESC | Вихід з програми |

## Архітектура
- `CameraProvider` — захоплення відео з камери
- `KeyProcessor` — обробка клавіатури та перемикання режимів
- `FrameProcessor` — обробка зображень (фільтри)
- `Display` — відображення результату та обробка миші
