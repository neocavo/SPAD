# Лабораторна робота №7 — Computer Vision та багатопотоковість

## Опис
Програма виконує детекцію облич в реальному часі за допомогою нейронної мережі ResNet-10 (OpenCV DNN). Детекція виконується в окремому потоці, щоб відео залишалось плавним.

## Вимоги до ОС та заліза
- **ОС:** Ubuntu 20.04+
- **Компілятор:** GCC 11+ або Clang 12+
- **CMake:** 3.10+
- **OpenCV:** 4.x
- **Камера:** вбудована або USB вебкамера
- **RAM:** мінімум 2 ГБ

## Клонування репозиторію
```bash
git clone https://github.com/neocavo/SPAD.git
cd SPAD/lab_7
```

## Встановлення залежностей та нейронної мережі
```bash
./preinstall.sh
```

## Збірка
```bash

```

## Запуск
```bash
./run.sh
```

## Або одною командою
```bash
./preinstall.sh && ./build.sh && ./run.sh
```

## Керування
| Клавіша | Дія |
|---------|-----|
| N | Нормальний режим |
| I | Інверсія кольорів |
| B | Gaussian blur |
| C | Canny фільтр |
| S | Фільтр Собеля |
| G | Відтінки сірого |
| F | Детекція облич (DNN) |
| ЛКМ | Намалювати кружок |
| ПКМ | Прибрати кружок |
| ESC | Вихід |

## Архітектура
- `CameraProvider` — захоплення відео з камери
- `KeyProcessor` — обробка клавіатури та перемикання режимів
- `FrameProcessor` — обробка зображень (фільтри)
- `Display` — відображення результату та обробка миші
- `FaceDetector` — детекція облич в окремому потоці (`std::thread` + `std::mutex` + `std::condition_variable`)

## Багатопотоковість
Детекція виконується у фоновому потоці — основний потік не блокується і відео залишається плавним (30+ FPS) навіть при затримці детекції 500мс.
